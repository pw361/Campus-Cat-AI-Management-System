# Campus-Cat-AI-Management-System

随着宠物经济快速发展，宠物医院、动物救助机构以及个人养宠用户对于宠物数字化管理需求不断提升。传统宠物管理系统主要以信息录入、列表查询和人工维护为主，存在以下问题：
■ **信息管理效率低**:宠物信息以Excel表格、纸质医疗记录、微信聊天记录等形式存在，工作人员需要人工整理猫猫基本信息、医疗记录、领养情况、疫苗信息等。
■ **业务查询成本高**:传统系统需要进入页面、设置筛选条件、导出数据及人工分析，人工工作量巨大，比如常见的分析问题最近7天哪些猫咪需要疫苗、当前有哪些健康状态异常的猫、过去一个月完成多少次领养等。
■ **专业知识获取困难**:普通养宠用户面对食欲下降、异常行为、饮食调整、疾病预防缺乏专业的查询渠道。
随着大语言模型（LLM）发展，AI具备：
- 自然语言理解
- 数据分析
- 智能问答
- 自动执行任务等能力。
因此，本项目设计：
Campus-Cat-AI-Management-System—— 一个融合AI Agent能力的新一代宠物管理平台。
